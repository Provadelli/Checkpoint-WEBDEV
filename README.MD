1. Modificando Atributos com JavaScript
Sobre a atividade

A atividade tem como objetivo aprender a modificar atributos de elementos HTML utilizando JavaScript, por meio dos métodos getAttribute() e setAttribute().

Foi criado um botão que permite trocar uma imagem por outra ao clicar, modificando os atributos src e alt.

2. CP2 — Calculadora de Supermercado
Sobre a atividade

A atividade consiste na criação de uma calculadora de supermercado utilizando HTML, CSS e JavaScript.

A calculadora permite informar o valor de um produto e sua quantidade. Ao clicar no botão Calcular, o JavaScript multiplica os dois valores e exibe o resultado da compra na tela.

Estrutura do projeto
text
CP2/
├── index.html
└── style.css

Tecnologias utilizadas
HTML: estrutura da calculadora.
CSS: estilização da página.
JavaScript: cálculo do valor total da compra.
