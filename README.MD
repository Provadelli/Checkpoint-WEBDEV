## Atividades Desenvolvidas

### 1. Modificando Atributos com JavaScript

#### Sobre a Atividade

Esta atividade tem como objetivo aprender a manipular atributos de elementos HTML dinamicamente utilizando JavaScript por meio dos métodos `getAttribute()` e `setAttribute()`. Foi criado um botão interativo que altera a imagem exibida alternando os atributos `src` e `alt`.

#### Estrutura do Projeto

```
Projeto 1/
├── index.html
├── style.css
├── imagem1.webp
└── imagem2.webp
```

#### Tecnologias Utilizadas

* **HTML5:** Estrutura base da página.
* **CSS3:** Estilização visual dos componentes.
* **JavaScript (ES6+):** Manipulação dos atributos das imagens via DOM.

### 2. CP2 — Calculadora de Supermercado

#### Sobre a Atividade

Consiste em uma aplicação web interativa que simula uma calculadora de supermercado. O usuário informa o valor unitário de um produto e a quantidade desejada. Ao acionar o botão **Calcular**, a aplicação processa a multiplicação e exibe o valor total da compra diretamente na tela.

#### Estrutura do Projeto

```
CP2/
├── index.html
└── style.css
```

#### Tecnologias Utilizadas

* **HTML5:** Estrutura da interface do usuário (formulários e exibições).
* **CSS3:** Estilização e formatação da calculadora.
* **JavaScript (ES6+):** Leitura de valores de entrada, execução da lógica matemática e renderização do resultado no DOM.

## Objetivo Geral

Praticar e consolidar os conceitos fundamentais do ecossistema front-end, focando na integração entre estrutura, estilo e comportamentos dinâmicos na Web.
